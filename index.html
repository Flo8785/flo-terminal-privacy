FLO Terminal — Privacy Policy

Last updated: 2026-09-30 · Contact: via GitHub repository Flo8785/flo-terminal-privacy (issues)

1. What FLO Terminal is

FLO Terminal is a personal, non-commercial, single-user dashboard application installed and run exclusively on the owner's own computer (localhost). It is not published, distributed, or made available to any other user. It connects to the owner's own Whoop and Withings accounts through the official developer APIs to display the owner's own health and fitness data (recovery, sleep, body measurements, activity) inside the dashboard.

2. What data we access and where it goes

  • Data retrieved from Whoop/Withings APIs (recovery scores, HRV, resting heart rate, sleep stages, weight, body composition, blood pressure) is stored only on the owner's local computer, in a local database file, for the owner's personal review.
  • The application runs an OAuth2 flow solely to obtain the owner's own authorization to read the owner's own data. The access and refresh tokens are stored locally on the owner's machine.
  • No data is transmitted to, shared with, or sold to any third party. There is no remote server: nothing leaves the owner's computer except the API requests to Whoop/Withings themselves, made directly by the application.
  • No analytics, no advertising, no tracking of any kind.

3. Data retention and deletion

Data is retained locally indefinitely for personal record-keeping. The owner can delete any record at any time from within the application, disconnect the integration (which removes stored API tokens), or revoke authorization entirely from their Whoop or Withings account settings. Deleting the application's local data folder removes everything permanently.

4. Contact

As a single-user personal application, the data controller is the application owner (the only user). For any question related to this policy, open an issue on the GitHub repository Flo8785/flo-terminal-privacy.

Français — Résumé

FLO Terminal est un tableau de bord personnel, non commercial, mono-utilisateur tournant exclusivement sur l'ordinateur de son propriétaire. Il lit les données de santé du compte Whoop/Withings du propriétaire (recovery, sommeil, mensurations) via les APIs officielles et les stocke uniquement en local, dans une base de données sur son propre ordinateur. Aucune donnée n'est transmise, partagée ou vendue à un tiers. Aucun serveur distant, aucune publicité, aucun suivi. Le propriétaire peut supprimer ses données à tout moment depuis l'application ou révoquer l'autorisation depuis les réglages de son compte Whoop/Withings.
